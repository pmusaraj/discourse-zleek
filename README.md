# LangChain-inspired Discourse theme

A conservative Discourse theme inspired by the visual language of [langchain.com](https://www.langchain.com/): dark navy surfaces, pale blue text, sky-blue accents, thin technical borders, compact rectangular buttons, and restrained glow/focus states.

This theme intentionally avoids copied assets, custom JavaScript, or heavy layout changes. It maps the reference site's design system onto standard Discourse UI patterns.
